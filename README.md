# 抖音弹幕朗读助手 (DanmuReader)

抖音弹幕朗读助手是一款通过本地弹幕网关抓取抖音直播间弹幕，并使用系统 TTS 引擎实时语音播报的桌面端工具。本项目基于 Qt 6 开发，支持 `Windows` 系统。

## 功能

- 实时弹幕接收（WebSocket 连接本地弹幕网关）
- TTS 语音朗读（Qt TextToSpeech 调用系统语音引擎）
- 音色选择（自动加载系统可用语音）
- 语速调节
- 礼物消息播报
- 弹幕列表实时显示
- 连接/断开控制与状态日志

## 使用方法

1. https://github.com/ape-byte/DouyinBarrageGrab/releases
下载并**以管理员身份运行** `WssBarrageService.exe`（DouyinBarrageGrab 弹幕网关），控制台显示 `ws://0.0.0.0:8888` 即启动成功
3. 浏览器打开抖音直播间（自己的或他人的均可用于测试）
4. 启动 `DanmuReader.exe`
5. 确认地址栏为 `ws://127.0.0.1:8888`，点击**连接**
6. 在 TTS 设置中选择音色、拖动语速滑块
7. 弹幕列表开始滚动，扬声器实时播报弹幕内容
8. 使用完毕点击**断开**或关闭窗口

> 无开播条件测试：浏览器进入任意正在直播的抖音直播间即可验证完整链路。

## 编译

1. 安装 Qt 6.x（勾选 MinGW 64-bit，并在 Additional Libraries 中勾选 WebSockets 和 Speech）
2. 打开 `DanmuReader.pro`
3. 构建 → 运行
