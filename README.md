# 抖音弹幕朗读助手 (DanmuReader)

抖音弹幕朗读助手是一款通过本地弹幕网关抓取抖音直播间弹幕，并使用系统 TTS 引擎实时语音播报的 Windows 桌面端工具。基于 Qt 6 (C++) 开发。

## 功能

- 实时弹幕接收（WebSocket 连接本地弹幕网关）
- 弹幕网关自动后台启动（无需手动运行网关程序）
- TTS 语音朗读（Qt TextToSpeech 调用系统语音引擎）
- 音色选择（自动加载系统可用语音）
- 语速调节
- 弹幕 / 礼物朗读独立开关
- 礼物消息播报
- 弹幕列表实时显示
- 连接 / 断开控制与状态日志

## 部署

1.下载 `DanmuReader-windows-x64.zip` 并解压

2.**以管理员身份运行** `DanmuReader.exe`（网关需要管理员权限安装证书和设置系统代理）

3.程序启动后会自动检测并拉起弹幕网关（首次运行网关会提示安装自签名证书，点击允许）

4.浏览器打开抖音直播间（建议用于监听自己的直播间）

5.确认地址栏为 `ws://127.0.0.1:8888`，点击**连接**

6.在 TTS 设置中选择音色、拖动语速滑块

7.弹幕列表开始滚动，扬声器实时播报弹幕内容

8.使用完毕点击**断开**或关闭窗口（程序退出时会自动关闭网关和代理）

> **提示**：无开播条件测试时，浏览器进入任意正在直播的抖音直播间即可验证完整链路。

## 注意事项

- 网关基于系统代理工作，**请保持程序后台运行**，不要中途关闭网关
- 首次启动若杀毒软件弹出拦截，请允许（证书安装需要）
- 若程序关闭后浏览器无法上网，请手动关闭系统代理：
  `设置 → 网络和 Internet → 代理 → 使用代理服务器 → 关闭`
- 仅支持 Chrome / Edge 浏览器，其他浏览器可能存在兼容问题

## 编译

1. 安装 Qt 6.x（勾选 MinGW 64-bit，并在 Additional Libraries 中勾选 WebSockets 和 Speech）
2. 打开 `DanmuReader.pro`
3. 构建 → 运行
